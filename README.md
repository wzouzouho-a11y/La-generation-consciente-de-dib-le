# La Génération Consciente de Dibôlé

Site officiel — version statique compatible avec GitHub Pages.

## Fichiers
- `index.html` : structure du site
- `style.css` : design responsive
- `script.js` : menu mobile et année automatique
- `assets/logo.png` : placez ici votre vrai logo

## Mise en ligne
Créez un dépôt GitHub, envoyez ces fichiers à la racine, puis activez GitHub Pages avec `main` comme branche de publication.
